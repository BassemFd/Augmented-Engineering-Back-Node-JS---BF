# Architecture document template

## Overview

High level description of the system and non-functional goals.

## Layers

- List layers and responsibilities (application / domain / infrastructure).

## Data flow

- Key flows and sequence descriptions. Include small diagrams or links to image assets.

## Integration points

- External services, messaging, databases and contracts.

## Deployment

- Topology, environments, and important infra configuration.

## Security & Governance

- Authentication, authorization, data handling notes.

## How to change the architecture

- Steps to propose and record changes: update doc, add rationale, notify owners.

## Diagrams & assets

- Keep images in `docs/assets/` and reference them from the document.
